💰 Finanly – Dashboard Financeiro

O Finanly é um projeto de dashboard financeiro desenvolvido para facilitar o controle de finanças pessoais. A aplicação permite registrar entradas e saídas, organizar movimentações por categoria e acompanhar o saldo financeiro de forma simples e intuitiva.

O objetivo é desenvolver uma interface prática, organizada e responsiva, proporcionando uma melhor visualização da situação financeira do usuário.

🚀 Tecnologias utilizadas

HTML5 – Estrutura da aplicação.

CSS3 – Estilização e responsividade.

JavaScript – Lógica e interatividade.

Bootstrap 5.3.8 – Componentes e layout responsivo.



📋 Funcionalidades

Visualização do resumo financeiro.

Exibição do total de entradas.

Exibição do total de saídas.

Cálculo automático do saldo atual.

Cadastro de novas movimentações financeiras.

Classificação de movimentações por categoria.

Identificação de entradas e despesas.

Histórico de movimentações.

🖥️ Interface

O dashboard é organizado em duas áreas principais:

Resumo financeiro

Total de entradas.

Total de saídas.

Saldo atual.

Nova movimentação

Descrição da movimentação.

Valor.

Categoria.

Tipo de movimentação (entrada ou saída).

📱 Responsividade

A interface utiliza recursos do Bootstrap e CSS para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência de utilização em computadores, tablets e dispositivos móveis.

⚙️ Como executar o projeto

1. Clone o repositório

git clone URL_DO_SEU_REPOSITORIO

2. Acesse a pasta do projeto

cd dashboardFinanceiro

3. Execute a aplicação

Abra o arquivo index.html diretamente no navegador ou utilize a extensão Live Server no Visual Studio Code.

O projeto foi desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento Front-end, trabalhando com estruturação HTML, estilização CSS, manipulação do DOM com JavaScript e criação de interfaces responsivas com Bootstrap.

Também busca desenvolver habilidades na construção de aplicações interativas e na organização de funcionalidades utilizando JavaScript.
